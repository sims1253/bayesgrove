# Update a node in the BayesGrove project graph

Update a node in the BayesGrove project graph

## Usage

``` r
bg_update_node(project, node_id, label = NULL, params = NULL, metadata = NULL)
```

## Arguments

- project:

  A `bg_handle`.

- node_id:

  The node ID to update.

- label:

  Optional new label.

- params:

  Optional new parameters.

- metadata:

  Optional new metadata.

## Value

The node ID.
