# Resume the workflow execution

Removes the pause marker, allowing the workflow to resume execution.
Pair with
[bg_pause](https://sims1253.github.io/bayesgrove/dev/reference/bg_pause.md);
reclassified `experimental` along with it (the wave-boundary pause
semantics are new in Milestone 3).

## Usage

``` r
bg_resume(project)
```

## Arguments

- project:

  A `bg_handle`.
